# Modelo de capítulo

Esta é uma página de **exemplo de capítulo**. Use-a como esqueleto: copie o arquivo, troque o conteúdo e cadastre a cópia no `book-config.js`. Apague esta página quando não precisar mais dela.

Comece com um parágrafo de abertura que diga, em duas ou três frases, o que o leitor vai aprender aqui e por que isso importa.

## Uma seção de conteúdo

Explique uma ideia por seção. Quebre o texto com `##` sempre que mudar de assunto — isso mantém a leitura leve e alimenta o índice "Nesta página".

Quando mostrar código, explique antes o que ele faz e depois comente as partes importantes:

```c
// Exemplo mínimo: uma caixa de mensagem.
#include <windows.h>

int WINAPI wWinMain(HINSTANCE hInst, HINSTANCE hPrev, PWSTR cmd, int show) {
    MessageBoxW(NULL, L"Conteúdo do seu livro aqui.", L"Capítulo", MB_OK);
    return 0;
}
```

> [!DICA]
> Intercale texto e código em pedaços pequenos. É mais fácil de ler do que um bloco gigante de código seguido de um bloco gigante de explicação.

## Outra seção

Continue assim, seção por seção, até cobrir o tema do capítulo. Ao final, feche com um parágrafo curto que resuma o que foi visto e adiante o próximo capítulo.

No próximo tópico você pode, por exemplo, aprofundar o assunto ou partir para um exercício prático.
