# Bem-vindo ao seu livro

Esta é a **página inicial de exemplo** do seu livro digital. Tudo o que você está lendo agora vem de um único arquivo Markdown:

```
conteudo/inicio/bem-vindo.md
```

Troque o conteúdo deste arquivo pela introdução do *seu* livro sobre programação Windows, e use as outras páginas de exemplo como referência de formatação.

## Como o modelo funciona

O site tem três partes que você vai mexer:

| Arquivo            | Para quê serve                                        |
| ------------------ | ----------------------------------------------------- |
| `book-config.js`   | Define o título do livro e a lista de capítulos       |
| `conteudo/`        | Onde ficam seus textos, em arquivos `.md`             |
| `styles.css`       | Cores, fontes e aparência (mexa só se quiser)         |

O fluxo é sempre o mesmo: você **escreve um `.md`** e **cadastra ele no `book-config.js`**. O índice lateral, a navegação e o modo escuro funcionam sozinhos.

> [!DICA]
> A página "Guia de formatação" mostra todos os recursos que você pode usar nos textos: títulos, código com cores, tabelas e caixas de destaque. Copie de lá o que precisar.
